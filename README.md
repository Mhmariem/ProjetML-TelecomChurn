# ProjetML-TelecomChurn
🌐 What if you could predict your customers’ future before they decide to leave? 🌟
This is the challenge we tackled with our ambitious project on Customer Churn Prediction in the Telecom Sector. A simple question with major strategic implications: How can we identify and retain customers before it’s too late?
🧩 Our project in two parts:
1️⃣ A supervised prediction, where we balanced the data using techniques like SMOTE, optimizing the performance of models such as Random Forest and Decision Tree.
2️⃣ An unsupervised analysis, combining PCA and K-Means clustering, to uncover the main causes and factors influencing customer churn.
✅ We used tools like joblib to preserve the min-max scalers, ensuring a smooth production deployment. By leveraging a reference dataset, our efforts achieved an accuracy almost equal to that reported in the reference scientific article. A validation that demonstrates the impact and relevance of our approach.
